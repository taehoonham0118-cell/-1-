## 1. 검증 ③ 최악 중력 토크 vs 기준 · 실제 정격

| 관절 | 구동기 (사양서) | 3 kg 최악 τ [N·m] | × 1.2 | PDR 기준 52 (팀장 10/19) | 실제 정격 / 피크 [N·m] | 실제 정격 대비 여유 % | 기준 ≤ 실제 정격 |
|---|---|---|---|---|---|---|---|
| shoulder_pitch | TQ ILM-E85x30 + Wolfrom 38.5:1 | 42.918 | 51.5 | 통과 | 118.8 / 381.7 | 176.8 | OK |
| shoulder_roll | TQ ILM-E85x30 + Wolfrom 38.5:1 | 39.767 | 47.72 | 통과 | 118.8 / 381.7 | 198.7 | OK |
| shoulder_yaw | TQ ILM-E85x30 + Wolfrom 38.5:1 | 11.849 | 14.22 | 통과 | 118.8 / 381.7 | 902.6 | OK |
| elbow | CubeMars RI85-PH KV85 + Wolfrom 38.79:1 | 11.784 | 14.14 | 통과 | 72.6 / 181.5 | 516.1 | OK |

- PDR 판정(기준 52 N·m)은 통과, 그리고 사양서 실제 정격(어깨 118.8 · 팔꿈치 72.6)이 기준 52 를 넘음 → 3 kg 페이로드 정적 유지는 정격 안 (여유 pitch 177 %)
- 단 **CAD(STEP)에는 8개 구동기가 모두 「RI85 제작건」** 으로 그려져 있음 — 사양서는 어깨 = TQ(모터 822 g, RI85 411 g 의 2배). 어깨 링크 질량 · COM 이 바뀌면 τ 도 바뀜 → 팀장 · A1 확인 필요 (어깨 3축 모두 TQ 인지 포함)

## 2. armature 를 넣으면 (kp 300 · dampratio 1 그대로, 왼팔 0.2 rad 계단, 다른 관절 유지 · 중력보상)

| 관절 | armature [kg·m²] | Mᵢᵢ + armature | kv (dampratio 1 재계산) | ω_n [rad/s] | 실효 감쇠비 ζ_hold | 오버슈트 % | 정착 2 % [s] |
|---|---|---|---|---|---|---|---|
| shoulder_pitch | 0 → 0.219 | 0.8466 → 1.0656 | 20.53 → 29.79 | 18.8 → 16.8 | 0.644 → 0.833 | 3.6 → 0.6 | 0.316 → 0.266 |
| shoulder_roll | 0 → 0.219 | 0.737 → 0.956 | 28.06 → 32.45 | 20.2 → 17.7 | 0.944 → 0.958 | 0.1 → 0.0 | 0.274 → 0.318 |
| shoulder_yaw | 0 → 0.219 | 0.0153 → 0.2343 | 4.25 → 16.76 | 140.0 → 35.8 | 0.992 → 1.0 | 0.0 → 0.0 | 0.044 → 0.164 |
| elbow | 0 → 0.098 | 0.0605 → 0.1585 | 6.24 → 12.82 | 70.4 → 43.5 | 0.733 → 0.93 | 1.6 → 0.3 | 0.062 → 0.122 |

- 가벼운 관절일수록 영향이 큼: shoulder_yaw 는 armature 0.219 가 링크 관성 0.0153 의 **14배** → ω_n 140 → 35.8 rad/s, 정착 0.04 → 0.16 s. 감속기 관절은 armature 가 동특성을 지배
- dampratio 라 kv 가 자동으로 커져(pitch 20.5 → 29.8) 오버슈트는 오히려 줄어듦 — kv 를 고정값으로 쓰면 재튜닝 필요 (armature_study.md 와 같은 결론). 6주차 Isaac `ImplicitActuatorCfg` 로 옮길 kv 도 armature 반영 후 값이어야 함
- 로터만이라 실제 armature 는 더 큼(기어열 TBD) → 감쇠비 · 정착시간은 이보다 더 느린 쪽
