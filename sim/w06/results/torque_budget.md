## 요약 · A팀 피드백

- **최소 여유율 (3 kg, 정격 대비)**: a2_doc shoulder_pitch 170 % (τ 43.95 / 정격 118.8), cad_ri85 shoulder_pitch 66 % (/ 72.6) → 두 case 모두 OK
- 1.0 kg(커리큘럼 페이로드) 최소 여유율: a2_doc 277 %, cad_ri85 131 %
- 집기 동작(테이블 높이 pick_point) 토크는 정적 최악의 27 %(pitch, 3 kg) — 팔을 내려 쓰는 자세라 작음. 예산을 정하는 것은 팔을 앞으로 · 옆으로 뻗은 정적 최악 자세
- 뻗기 동작(1.5 s) 동적 최대 = 정적 최악 + 2.4 % (pitch 3 kg 43.95 N·m). 관성 토크는 1/T² 로 커짐(아래 표)
- **PDR 52 기준(정격 ≥ 최악 × 1.2) 은 정적 기준으로 통과**(5주차 ③ 21.2 %). 동적 뻗기까지 넣으면 pitch 3 kg 여유 18.3 %(주의), 관절 속도 한계(3.0 rad/s) 까지 빠르게 뻗으면 46.14 N·m → 12.7 %(주의). 실제 정격(TQ 118.8 · RI85 72.6) 대비는 모두 OK
