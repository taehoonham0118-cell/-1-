## 1. 도메인 랜덤화(DR)는 무엇을 위한 것인가

- sim-to-real 차이의 원천: 질량 · COM, 마찰, armature · 감쇠 · 쿨롱 마찰, 게인 · 토크 상수 · 포화, 센서 잡음 · 편향, 제어 지연, 환경 치수(테이블 높이). 시뮬은 한 값을 쓰지만 실물은 「모르는 한 값」 → 그 값이 범위 어딘가에 있어도 정책이 돌게 학습 · 검증한다(Tobin 2017).
- **범위 근거** = 가정값 표의 불확실도 + 사양(A2): 측정 전 가정값(μ 1.0, 파지력 40 N, 테이블 0.70 m)은 넓게, 사양서가 있는 값(armature 로터값)은 사양이 빼먹은 부분(기어열)만큼, 우리가 정하는 값(게인)은 구현 오차(토크 상수 ±10 %)만큼.
- **너무 좁으면** 실물 값이 범위 밖 → 시뮬에서만 되는 정책(과적합). **너무 넓으면** 풀 수 없는 과제가 섞여 학습 신호가 흐려지고, 정책이 보수적(느리게 · 세게 잡기)으로 됨 — 우리 결과: 동시 랜덤화 성공 없음 100 → 좁게 99 → 기준 98 → **넓게 72 %**, ×2 실패 28건 중 17건이 테이블 충돌(테이블 +14 mm 넘으면 지금 그리퍼 형상으로는 원리적으로 실패).
- **하나씩(OAT) vs 동시**: 하나씩은 원인이 분명(순위 · 경계 찾기), 동시는 상호작용 포함 실제 조건(최종 강건성 수치). 둘 다 같은 seed 로 짝 비교해야 잡음이 줄어듦.

## 2. 9주차 결과 요약 (seed 40개 · 공칭 40/40)

| 순위 | 파라미터 | ×1 범위 → 최저 | ×2 → 최저 | 깨지는 곳 · 이론 |
|---|---|---|---|---|
| 1 | 테이블 높이 오차 | ±10 mm → 40/40 | ±20 mm → **0/40** | +12 mm 15/40 · +14 mm 0/40 = 원기둥 손바닥 여유 11 mm · 손끝 여유 16 mm(− 계획 점검 5 mm) |
| 2 | 손가락 · 물체 μ | 0.5 ~ 1.2 → 39/40 | 0.1 → **15/40** | m ≤ 2μF/g (F 40 N) — seed 별 일치 261/262 |
| 3 | 물체 위치 측정 편향 | 0 ~ 10 mm → 39/40 (목표 오차 +2.12 mm) | 20 mm → 38/40 | 25 mm 31/40 = 벌림 여유 (110 − 60)/2 = 25 mm |
| 4 ~ | 베이스 kv · 쿨롱 마찰 · 물체 질량 · 파지력 … | 40/40 | 38 ~ 40/40 | 팔 질량 ±10 % 는 pitch 토크 25.1 ~ 29.2 N·m 로만 드러남 |

- 「성공률」은 전문가 정책(측정 기반 상태기계 + 피드백)이 견디는 동안 포화되므로, **×2 스트레스 + 연속 지표(목표 오차 · 토크)** 를 같이 봐야 순위가 나옴.
- 둔감했던 것(armature · 감쇠 · kp · 지연 40 ms · 손가락 질량)도 「필요 없다」가 아니라 **이 과제 · 이 속도에서** 둔감 — 빠른 동작 · 토크 예산 · Isaac 게인 이식에는 그대로 필요.
- 수치 설정(dt 0.25 ~ 1.5 ms · solref · impratio)은 seed 1000 ~ 1039 에서 거의 영향 없음(8주차 1 ms 발산 seed 1080 은 이 40개 밖) → 수치 설정은 랜덤화가 아니라 「발산 여부 점검」 대상.
- 발견: MuJoCo 는 두 geom 마찰 중 **큰 값**을 씀 → 가정값 표 S16 테이블 0.8 은 실제로 쓰이지 않음(물체 1.0 적용). PhysX 기본은 평균 → Isaac 이식 때 결합 규칙을 맞춰야 같은 μ.

## 3. 행동 복제(BC)와 공변량 이동

- BC = 시연 (obs, action) 쌍으로 지도학습 π(obs) ≈ action. 학습 / 검증 분리(에피소드 단위 — 같은 에피소드의 이웃 스텝이 양쪽에 들어가면 검증 오차가 거짓으로 작아짐), 입력 · 출력 정규화.
- **공변량 이동**: 학습은 전문가가 간 상태 분포에서만 했는데, 롤아웃에서는 작은 오차로 처음 보는 상태에 들어가고 거기서 오차가 더 커짐(누적, Ross 2011: 오차가 지평 T 에 대해 T² 로 커질 수 있음).
- 임시 BC(단순 MLP): 검증 MSE 0.0063 으로 작은데 **롤아웃 0/20** (2 s 안에 그리퍼를 닫음). 박종진도 청킹 없는 BC 는 0/50.
- 박종진 BC(DART + 액션 청킹 25) × 내 랜덤화(`results/bc_eval_pjj.md`): 랜덤화 없음 **18/50** → 동시 ×1 **4/50** → ×2 0/50 (전문가 49 · 46 · 32). BC 하나씩 민감도 Top 3 = **테이블 −10 mm 0/25 · 지연 20 ms 0/25(들어 올림 0) · 팔 질량 −10 % 4/25** (공칭 8/25) — 전문가 Top 2 · 3 인 μ · 편향은 BC 에 영향 없음
- 왜 다른가: 전문가는 측정 피드백(접촉을 보고 놓기, 기준 궤적 추종)이라 동역학 차이를 흡수, BC 는 「시연에서 본 상태 → 명령」을 외움 → 학습 데이터에 없던 **지연 · 질량(동역학)** 과 **테이블 높이(관측 분포 밖)** 에서 무너짐. 지연 10 ms 이상 표본 27개는 하나도 못 듦 = 랜덤화가 공변량 이동을 수치로 드러낸 것
- 대책: 시연 · DART 를 랜덤화 환경에서 수집(도메인 랜덤화 + BC), 관측에 직전 명령 · 접촉 추가, 지연은 제어 주기 안(≤ 10 ms)으로 실기 요구
- 줄이는 방법: DAgger(BC 가 간 상태를 전문가가 다시 라벨링 — 우리 전문가는 내부 기준 궤적을 가져서 「상태 → 단계 · 목표」 함수를 분리해야 가능), DART(잡음 주입), 액션 청킹(ACT: k 스텝 묶어 예측 → 결정 횟수 ↓), 단계(phase) 입력 · 그리퍼 분류 출력, 데이터 늘리기.

## 4. Isaac Lab 대응 (상세 `docs/isaaclab_event_mapping.md`)

- 랜덤화 = `EventTermCfg(func, mode, params)`. 질량 · 재질 · 관절 · 게인은 `startup`(env 마다 다른 값 → 4096 env 가 분포를 덮음), 초기 자세 · 테이블 높이는 `reset`.
- Event 가 아닌 것: 측정 편향 = Observation noise(`NoiseModelWithAdditiveBiasCfg`), 지연 = `DelayedPDActuatorCfg`, dt · solref · impratio = 엔진 설정(PhysX 에는 solref 가 없음).

## 5. 구술 대비

- ① 범위를 너무 넓게 / 좁게: 좁으면 실물이 범위 밖(과적합), 넓으면 풀 수 없는 과제가 섞여 학습이 흐려지고 보수적 정책. 근거 = 가정값 표 불확실도 + A2 사양 + 우리가 아는 구현 오차. 수치: 동시 100 → 99 → 98 → 72 %(×2), ×2 실패 17/28 이 테이블 충돌. → 실측 후 범위 = 평균 ± 2σ 로 좁힘
- ② Top 3 실측: 테이블 = 거리계 5점 + 끝점 터치(목표 ±2 mm, 여유 11 mm), μ = 경사면 tanθ + 파지 당김 P/(2F)(목표 ±0.05, 3 kg 경계 0.37), 위치 편향 = 알려진 20점 인식 오차(목표 ≤ 5 mm, 여유 25 mm). 상세 `docs/sysid_plan.md`
