## 1. 게인 통일 — 왜, 어떻게

- 6주차까지 MuJoCo 빌드는 `kp 300 · dampratio 1`(컴파일 시 qpos0 관성으로 kv 계산), Isaac 패키지(`actuator_params.md`)는 week06 고정 게인 → **두 시뮬 게인이 달랐음**. 고정 kv 는 Isaac `ImplicitActuatorCfg` damping 과 같은 뜻이라 이것으로 한 벌
- 방법: `actuator_params.json` 에 `joint_gains`(관절별 kp · kv) 추가, `build_v1.py` 가 팔 position 액추에이터에 kp · kv 를 직접 씀(dampratio 제거). 빌드 결과 바뀌는 곳 = b1.xml 액추에이터 8 줄 + class 2 줄(dampratio 삭제), URDF · 질량 변화 0
- 통일 값: **pitch 400 · 31.0 / roll 350 · 27.5 / yaw 300 · 15.0 / elbow 300 · 11.0** (N·m/rad · N·m·s/rad)
- 검증 5종(박종진 `validate_model.py`, 패치 빌드) 모두 통과. 검증 ② 처짐(보상 끔, 앞으로 수평): **4.83° → 3.63°** (이론 τg/kp = 25.40/300 → 25.40/400 rad = 4.85 → 3.64°), roll 상한 4.33 → 3.72°. 중력보상 B 켜면 0.00°

## 2. 짐 0 · 3 kg 계단응답 — 3 kg 이면 감쇠가 모자람

- 2차계 근사: ω_n = √(kp/Mᵢᵢ), ζ = kv / (2√(kp·Mᵢᵢ)). 짐은 Mᵢᵢ 만 키움 → ω_n · ζ 둘 다 √(M₀/M₃) 배로 감소
- 앞으로 수평 pitch: Mᵢᵢ 1.066 → 2.129 kg·m²(2배) → ζ 0.75 → **0.53**, OS 2.96 → **14.5 %**, 정착 0.302 → 0.642 s → R3(≤ 5 % · ≤ 0.30 s) 미통과 (302 자세 최악, 4 관절 모두 미통과)
- 짐 질량 중력 FF(아는 짐)는 **정상상태 처짐만** 없애고 동특성(OS · 정착)은 그대로 (14.58 vs 14.51 %) — 중력은 위치 함수, 감쇠는 관성 문제
- 대책 = 짐 질량을 알 때 **관성 비례 게인 스케줄** kp · kv × Mᵢᵢ(3 kg)/Mᵢᵢ(0 kg): pitch 5.22 % · 0.340 s, elbow 2.24 % · 0.190 s 로 크게 개선(결합 관성 때문에 0 kg 와 완전히 같지는 않음). Isaac 에선 런타임 stiffness · damping 변경 필요 → 대안 = 짐을 들 때는 궤적을 느리게(계단 대신 5차 궤적) 하거나 관성 FF(M(q)q̈_ref)
- **새로 찾은 점**: 6주차 확장 점검(영점 + 무작위 300)에 「앞으로 수평」 자세가 없었음 → 넣으니 0 kg pitch 정착 0.302 s(기준 0.30 s, +2 ms 경계). OS 2.96 % 는 통과

## 3. 짐 질량 중력보상 — 알 때 / 모를 때 (구술 ①)

앞으로 수평 왼팔, 0.5 s 에 3 kg 잡기 → 3.5 s 놓기 (`gain_payload.md` 3절, `week07_payload_comp.png`)

| 방식 | 유지 중 끝점 처짐 | 놓은 뒤 | 위험 |
|---|---|---|---|
| 모르는 짐(FF 없음) | **34.7 mm** (이론 K⁻¹Jᵀmg → 34.8 mm, pitch 2.51° · elbow 1.68°) | 0.31 s 에 복귀 | 오차 = 짐 토크 / kp, kp 를 키우면 줄지만 0 은 아님 |
| 아는 짐 FF | 0.0 mm | 0 | 질량 · 잡는 순간을 알아야 |
| 질량 틀림 2 kg / 4 kg 가정 | 11.6 mm 처짐 / 11.6 mm 들림 | – | 잔차 = (1 − m̂/m) × 34.7 mm, 이론과 같음 |
| 적분항(PI, Ti 0.5 s) | 0.1 mm (≈ 1.5 s 걸림) | **32 mm 튀어 오름**, 1.95 s 복귀 | 적분값이 m g Jᵀ 를 기억 → 놓을 때 반대로 튐. 포화 · 접촉(테이블에 걸림)에서 와인드업 → 리셋 · 클램프 필요 |
| 질량 추정(정지 0.2 s, PD 토크 최소자승) → FF | 1.7 mm (m̂ 2.851 kg, −5 %) | **34 mm 들린 채 유지** | 움직이는 중엔 관성 · 속도 항이 섞여 편향, FF 를 계단으로 켜면 토크 튐(−59 N·m 순간). 놓기 감지(그리퍼 열림 신호)로 m̂ = 0 리셋 필수 |

- 추정식: 정지 상태 PD 토크 τ_pd = m g J_zᵀ (J_z = 짐 COM 자코비안 z 행) → m̂ = J_z τ_pd / (g ‖J_z‖²)

## 4. 전신 자코비안 · 가중 DLS · resolved-rate

- `mj_jacSite` 는 nv 전체 열을 주므로 베이스 TX · TY · RZ 열을 같이 뽑으면 끝점 위치 자코비안 **3×7**. TX · TY 열 = world x · y 단위벡터(slide 축 world 고정), RZ 열 = ẑ × (p − p_RZ)
- 가중 DLS: q̇ = W⁻¹Jᵀ(JW⁻¹Jᵀ + λ²I)⁻¹ ẋ — W 는 「움직이는 비용」. 베이스 W 를 키우면 팔을 먼저 쓰고, 팔이 뻗어 그 방향 자코비안이 작아질 때 그 성분을 베이스가 가져감. 너무 크면(W 100) 팔이 한계에 먼저 닿아 경로 B 에서 오차 116 mm
- 영공간: q̇ = J#ẋ + (I − J#J)q̇₀, 차원 = 7 − 3 = **4** (팔만 4 − 3 = 1). 여기서는 q̇₀ = 팔 관절 한계 회피(범위 중앙 쪽 기울기)
- resolved-rate(CLIK): ẋ_cmd = ẋ_ref + K(x_ref − x), K 10 1/s, 100 Hz 제어 / 500 Hz 시뮬. 베이스 = velocity 액추에이터에 q̇[TX, TY, RZ], 팔 = position 목표 q_ref += q̇Δt. 속도 한계(팔 3 rad/s · 베이스 1.5 m/s · 90 °/s) 넘으면 q̇ 전체를 같은 비율로 줄여 방향 유지
- yaw 변환: MuJoCo slide 는 world 축이라 world 속도를 그대로 넣지만, 실제 베이스는 로봇 기준 명령 → v_body = R(yaw)ᵀ v_world (로그 `vbody_x · vbody_y`)

| 경로 | 팔만 | 전신 W 10 | 전신 W 1 | 전신 W 100 |
|---|---|---|---|---|
| A 전방 z 0.75 m, x 0.30 → 0.80 | **실패** (끝 오차 323 mm, 팔 도달 ≈ 0.44 m) | 최대 7.6 · RMS 4.8 mm, 직선 수직 0.4 mm, 끝 0.5 mm, 베이스 +0.40 m · yaw −7.5° | 7.7 mm, 베이스 0.44 m | 10.4 mm |
| B 측방 z 0.90 m, y 0.40 → −0.20 | **실패** (318 mm) | 5.8 mm, 베이스 −0.25 m · yaw −5.6° | 7.9 mm, 베이스 0.53 m | 116.5 mm(이동 중), 끝 1.2 mm |

- 이동 중 오차 5 ~ 8 mm 의 원인: 팔 서보 속도 지연(kv·q̇/kp) + 베이스 velocity 1차 지연(M/kv = 78/200 ≈ 0.39 s). 끝점은 CLIK 피드백이 메움
- 노션 예시 「0.6 m」: 바닥 기준이면 팔 최저 도달 0.606 m 아래, 베이스는 높이를 못 바꿈 → 전신으로도 불가(구조 한계, 손목 · 몸통 높이 변경 문제) → 0.75 m 사용

## 5. 베이스 가감속이 팔에 주는 추가 토크 (구술 ②)

- 원인: 베이스(팔 뿌리)가 가속하면 팔 좌표계에서 각 링크에 관성력 −mᵢa 가 걸림. 크기 = 질량행렬 결합 블록 **τ_add = M_ab(q)·q̈_b** (+ yaw 회전 중이면 원심 · 코리올리 c(q, ω))
- 손 검산(영점, 팔 늘어뜨림, 전방 가속 → pitch): 진자 Σmᵢhᵢ = 4.375 kg·m = M_ab[pitch, x] → 1 m/s² 에 4.37 N·m
- 계수(3,000 자세 최대, 3 kg): pitch 4.37 · roll 4.06 N·m per m/s², yaw 각가속 1 rad/s² 당 roll 2.83, ω 90 °/s 원심 roll 4.23 N·m
- 시뮬 확인: 속도 램프(1 m/s²) 명령에서 시뮬 Δτ = 이론(차 ≤ 6 %, 예 영점 x 3.78 vs 3.80 N·m). 속도 계단은 가속 피크가 짧아 서보가 걸러 시뮬 < 강체 이론(이론 = 상한)
- 예산(방향 최악 합산, 보수적): 설계 가정 a 1.0 m/s² · α 1.57 rad/s² · ω 1.57 rad/s → pitch 42.92 → **44.12**, roll 39.77 → **41.57** N·m. 최소 여유 a2_doc pitch **169 %**, cad_ri85 pitch **65 %** → OK. PDR 52 기준 pitch 17.9 %(주의, 6주차 18.3 %)
- 현재 베이스 velocity kv 200 · 50 에 최대 속도를 계단 명령하면 a₀ = 200·1.5/78.1 = 3.84 m/s², α₀ = 50·1.571/4.16 = 18.9 rad/s² → roll 80.2 N·m(cad_ri85 정격 72.6 초과) → **베이스 명령에 가속 제한이 조건**. 하체 실제 가속 사양은 미수령(가정값)

## 6. B1 업무와의 연결

- 통일 게인 = MuJoCo ↔ Isaac 같은 숫자 → 실습 PC 에서 검증 ② ③ 재현 시 비교 기준이 하나
- 짐 3 kg 감쇠 부족 → 8주차 집기 시나리오(실제 물체 질량 0.2 ~ 3 kg)에서 궤적 속도 · 게인 스케줄 선택 근거, 놓기 순간 처리(적분 리셋 · m̂ 리셋)는 상태기계의 「놓기」 단계 조건
- resolved-rate + 가중 DLS = 8주차 전문가 정책(전신 IK + 궤적)의 저수준 제어기. 베이스 가속 제한 · 팔 우선 가중치 기본값 W 10
- 토크 예산에 베이스 가속 열 추가 → A팀 · 하체 담당에게 「베이스 가속 ≤ 1 m/s², yaw ≤ 1.57 rad/s²」 조건 전달
