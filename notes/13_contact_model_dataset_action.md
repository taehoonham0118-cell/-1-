## 1. MuJoCo 접촉은 「부드러운 제약」

- 접촉은 강체 충돌이 아니라 제약 하나 = 「관통 r 을 없애는 쪽으로 기준 가속도 a_ref = −b·v − k·r 를 따르라」. 이것을 얼마나 세게 따를지가 임피던스 d ∈ (0, 1).
- **solref = (timeconst, dampratio)** → 「스프링 · 댐퍼」. b = 2/(d_max·tc), k = d(r)/(d_max²·tc²·ζ²). tc 가 작을수록 딱딱(빨리 복원), ζ 는 감쇠비(1 = 임계감쇠). 규칙: tc ≥ 2·dt (MuJoCo 문서).
- **solimp = (dmin, dmax, width, …)** → 임피던스 d 가 관통 0 에서 dmin, width 만큼 들어가면 dmax. d 가 1 에 가까울수록 제약을 세게 지킴(관통 작음) 대신 수치적으로 딱딱함.
- 정상상태 관통 r ≈ (1 − d)/d · a₀/k ∝ tc² · ζ² — 스윕 확인: tc 0.01 → 0.02 에서 0.22 → 0.52 mm, ζ 1 → 2 에서 0.22 → 0.52 mm, solimp 0.95 · 0.99 → 0.99 · 0.999 에서 0.22 → 0.04 mm.
- **마찰**: friction = (미끄럼 μ, 비틀림, 구름). condim 3 = 미끄럼만, 4 = + 비틀림(물체가 파지축으로 도는 것 억제), 6 = + 구름. 마찰 원뿔 기본(pyramidal)은 힘이 충분해도 천천히 흘러내림(크리프) → elliptic + impratio 10(마찰 제약을 법선보다 10배 세게) — 박종진 54/54 확인.
- 파지 유지 이론: 손가락 2개 → 2μF ≥ mg → F_min = mg/(2μ). 3 kg · μ 1.0 → 14.7 N, 가정 40 N 은 2.7배.

## 2. 구술 ① — solref · solimp 의 물리적 의미, 뚫릴 때 · 미끄러질 때 무엇을 바꾸나

| 증상 | 원인 | 바꿀 값 (방향) | 대가 | 우리 데이터 |
|---|---|---|---|---|
| 손가락이 물체를 **뚫음**(관통 큼) | 접촉이 너무 부드러움 | solref tc ↓(0.02 → 0.01), solimp dmin · dmax ↑(→ 0.99), width ↓ | 너무 딱딱하면 tc < 2·dt 쪽에서 발산 | tc 0.005 · solimp 0.99 는 무거운 물체 발산 1 → 11 · 5건 |
| **미끄러짐**(천천히 흘러내림) | 마찰 원뿔 크리프, μ · 파지력 부족 | cone elliptic + impratio ↑, μ 확인, 파지력 F ≥ 1.5 F_min, condim 4(회전) | impratio 를 낮추면 크리프 · 발산 ↑ | impratio 1 → 발산 12건 |
| 물체가 **튕기거나 발산** | 접촉 강성 · 가벼운 손가락의 빠른 모드를 dt 가 못 따라감 | **dt ↓**(1 → 0.5 ms), 손가락 질량 ↑, 닫는 속도 제한 | 계산 ×1.9 | seed 1080 · 3 kg 원기둥: dt 0.5 ms 만으로 9 → 19/20, 100/100 |

- 결론: 「뚫림」은 solref · solimp(정적 관통), 「미끄러짐」은 마찰 원뿔 · μ · 힘, 「발산」은 접촉 강성 대 적분 간격 문제. seed 1080 은 세 번째 — 각속도가 0.1 → 17 rad/s 로 지수적으로 커짐(물체가 내려간 것이 아님).

## 4. 구술 ② — action 을 「관절 목표」 vs 「끝점 목표」로 저장할 때

| | 관절 목표 (v1.0 채택) | 끝점 목표 (위치 + 그리퍼 축) |
|---|---|---|
| 재생 | 넣은 값 그대로 → **비트 일치(차 0)** | 매 주기 IK 필요 → 직전 해에서 시작하면 10/10 성공이지만 관절 목표가 최대 2.84° 달라짐 |
| 해의 모호성 | 없음 (자세 하나) | 4-DOF + 베이스: 같은 끝점에 여러 팔 자세. 이력 없이(영점에서) 풀면 상자 시연 2개에서 62 ~ 64 % 주기가 다른 가지(최대 286°), IK 실패 주기(잔차 최대 660 mm)도 생김 |
| 실기 · 이식 | 서보에 그대로 · 관절 한계 · 토크 확인 쉬움 | 로봇마다 IK 가 달라도 같은 데이터 사용(다른 로봇 · 손목 추가 후에도 재사용), 작업 의미가 직관적 |
| 학습(BC) | 출력 차원 작음(팔 4), 하지만 자세 오차가 끝점에서 팔 길이만큼 커짐 | 끝점 오차를 직접 줄임, 물체 위치와 같은 좌표라 일반화 쉬움. 대신 IK 실패 · 특이점 · 가지 바뀜을 정책 밖에서 처리해야 함 |
| 계산 | 0.46 ms/주기 | 0.76 ms/주기 (IK 30회) |

- 결정: **저장은 관절 목표**(재생 · 결정성 기준), 끝점 목표는 같은 파일에서 FK 로 언제든 만들 수 있으므로 9주차 BC 에서 두 출력 형식을 비교(박종진과 합의 항목).
