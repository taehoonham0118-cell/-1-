## 3. 문제 · 해결 과정

| 증상 | 원인 | 해결 |
|---|---|---|
| ×1 범위에서 거의 모든 파라미터 40/40 → 순위가 안 나옴 | 전문가 정책이 측정 기반 피드백이라 근거 범위 안에서는 견딤(성공률 포화) | ×2 스트레스 + 연속 지표(목표 오차 · 토크) 추가 → 순위 = ×2 하락 → ×1 하락 → 목표 오차 |
| 팔 질량을 바꿔도 처짐이 없음 | MuJoCo gravcomp 가 바뀐 질량을 그대로 보상(완벽한 모델 가정) | gravcomp = 1/s 로 공칭 질량만 보상 → 모델 오차 재현 |
| 테이블 μ 를 바꿔도 효과 없음 | MuJoCo 마찰 결합 = 두 geom 중 max → 물체 1.0 이 이김(테이블 0.8 은 원래부터 미사용) | 손가락 · 물체를 같이 바꿈, 매핑표에 PhysX(평균)와 차이 기록 |
| 「손끝 여유 12 mm」(전문가 코드 주석)로는 +12 mm 실패를 설명 못 함 | 실측 손끝 16 mm, 원기둥 손바닥 여유 11 mm — 실패는 원기둥 24개만 | `w09_clearance.py` 로 실측 → 경계 설명 정정, 박종진에 주석 정정 전달 |
| PyTorch 설치 실패 → 박종진 .pt 를 못 읽음 | 클라우드 프록시가 download.pytorch.org 차단 | `pt_numpy.py` 로 .pt(zip · pickle)를 직접 읽어 같은 MLP 를 numpy 로 — 박종진 성공률 18/50 재현 |
| 박종진 eval_bc 는 테이블 · 지연 · 편향 · 물체 질량을 못 바꿈 | rand_dyn.apply 는 모델 값만, reset() 이 질량을 덮어씀 | 코드를 고치지 않고 `sample_task` · `live_features` · `mj_step` 을 감싸서 적용 |
| 내 판정기가 전문가 2건을 실패로 봄 | 들기 높이 기준 50 mm > 실제 들기 48.6 mm | 30 mm 로 고쳐 재실행 → 전문가 100/100 (박종진 판정과 일치) |

## 5. 구술 대비 (11/19 목) — 상세: notes/14 §5

- Q1: 좁으면 실물이 범위 밖(시뮬 과적합), 넓으면 풀 수 없는 과제가 섞여 학습이 흐려지고 보수적 정책 — 동시 100 → 98(×1) → 72 %(×2), ×2 실패 17/28 이 테이블 충돌. 근거 = 가정값 표 불확실도 + A2 사양 + 구현 오차, 실측 후 평균 ± 2σ
- Q2: 테이블 = 거리계 5점 + 끝점 터치(±2 mm, 여유 11 mm), μ = 경사면 tanθ + 파지 당김 P/(2F)(±0.05, 3 kg 경계 0.37), 위치 편향 = 알려진 20점 인식 오차(≤ 5 mm, 여유 25 mm)
