## 3. 문제 · 해결 과정

| 증상 | 원인 | 해결 |
|---|---|---|
| MuJoCo 빌드(dampratio)와 Isaac 패키지(고정 kv) 게인이 다름 | 6주차 튜닝 값이 메모리 편집으로만 쓰이고 빌드에 안 들어감 | `joint_gains` + 빌드 패치, 박종진 합의 요청 |
| 노션 예시 「테이블 높이 0.6 m」 직선이 전신으로도 안 됨 | 바닥 기준 0.6 m 는 팔 최저 도달 0.606 m 아래, 베이스는 높이를 못 바꿈 | 6주차 pick_point 높이 0.75 m 로 진행, 구조 한계로 기록 |
| 짐 FF 를 켰는데 3 kg 오버슈트가 그대로 | 중력 FF 는 위치 함수 — 감쇠비는 관성(Mᵢᵢ)이 정함 | 관성 비례 게인 스케줄 · 느린 궤적을 대책으로 분리 |
| 추정 FF 를 켜는 순간 pitch 토크 −59 N·m 튐 | FF 를 계단으로 넣음 | 램프로 넣어야 함(8주차 상태기계에 반영할 항목) |
| W 100 에서 경로 B 이동 중 오차 116 mm | 베이스를 너무 아껴 팔이 관절 한계에 먼저 닿음(여유 0°) | 기본 W 10, 영공간 한계 회피 유지 |
| 베이스 계단 명령 추가 토크가 이론보다 작음 | 가속 피크가 수 ms 라 팔 서보(유한 강성)가 걸러냄 | 이론을 상한으로 쓰고, 램프 명령으로 시뮬 = 이론 확인 |

## 4. B1 업무와의 연결

- 통일 게인 = MuJoCo ↔ Isaac 같은 숫자 → 실습 PC 에서 검증 비교 기준 하나
- 3 kg 감쇠 부족 · 놓기 처리 → 8주차 집기 상태기계(파지 · 놓기 단계 조건, 적분 · m̂ 리셋)
- resolved-rate + 가중 DLS = 8주차 전문가 정책 저수준 제어기
- 베이스 가속 조건(≤ 1 m/s² · ≤ 1.57 rad/s²) → A팀 · 하체 담당 전달 항목

## 5. 구술 대비 (11/5 목) — 상세: PC 7주차_작업/구술_답변_복붙용_7주차.md · notes/12 §3 · §5

- Q1: 미보상이면 오차 = K⁻¹Jᵀmg (3 kg 34.7 mm), 적분은 0 으로 만들지만 놓을 때 32 mm 튐 · 와인드업, 추정은 정지 구간에서만 정확(−5 %) · 놓기 감지 없으면 34 mm 들림
- Q2: 뿌리 가속 → 관성력 −mᵢa, τ = M_ab(q)·q̈_b (+ 원심), 질량행렬 결합 블록으로 3,000 자세 최대 → pitch 4.37 N·m per m/s², 손 검산 Σmh 4.375, 램프 시뮬 일치 ≤ 6 %
