## 3. 문제 · 해결 과정

| 증상 | 원인 | 해결 |
|---|---|---|
| 손가락 단독 장치에서는 96조합 모두 유지되는데 로봇 시나리오에선 발산 | 정적 관통은 solref · solimp 가 정하지만, 발산은 팔 · 베이스 · 손가락 equality 가 묶인 전체 계의 적분 문제 | 박종진 시나리오 그대로 돌리는 스윕으로 원인 판정 |
| solref 를 부드럽게 하면 나아질 것으로 예상했으나 악화 | 관통이 커져 낙하가 늘고 발산은 그대로 — 원인이 「강성 과대」가 아니라 「강성 대비 dt」 | dt 를 바꾼 설정만 해결 → 원인 표에 기록 |
| dampratio 0.7 에서 seed 1080 만 성공 | 우연(3 kg 20회는 9 → 10/20) | 한 seed 결과로 판단하지 않고 38건 · 20회로 확인 |
| 3.0 kg 고정 토크 실행에서 yaw 32.8 N·m 가 나옴 | 발산 에피소드의 토크(물리값 아님)가 섞임 | dt 0.5 ms + 성공 에피소드만 집계 → yaw 2.2 N·m |
| 초안 샘플이 명세 검사에서 위반 10개 | 파생 필드 · 속성 · spec 문자열 차이 | `upgrade` 로 원본 배열은 그대로 두고 추가 → 재생 차 0 유지 |

## 5. 구술 대비 (11/12 목) — 상세: notes/13 §2 · §4

- Q1: solref = 접촉 스프링 · 댐퍼(시간상수 · 감쇠비), solimp = 관통에 따른 임피던스(얼마나 세게 제약을 지키나). 뚫리면 tc ↓ · dmin/dmax ↑(관통 ∝ tc² ζ², 0.22 → 0.04 mm), 미끄러지면 elliptic + impratio ↑ · μ · 파지력 F ≥ 1.5 F_min, 발산이면 dt ↓ — seed 1080 은 발산(dt 0.5 ms 로 3 kg 9 → 19/20)
- Q2: 관절 목표 = 재생 비트 일치 · 서보에 그대로 · 해 하나, 대신 로봇 종속 · 끝점 오차 증폭. 끝점 목표 = 로봇 독립 · 작업 의미 직관, 대신 IK 필요(직전 해 시작 ≤ 2.84°, 이력 없으면 62 ~ 64 % 다른 가지) → 저장은 관절, 끝점은 FK 파생
