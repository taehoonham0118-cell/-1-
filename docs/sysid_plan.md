# 실기 시스템 식별 계획서 v0.2 (week09 작성 · week10 11/20 토크 판정 기준 갱신, 함태훈)

- 목적: 구동기 · 그리퍼 · 시연 환경 실물을 받으면 **가정값을 측정값으로 바꾸고 랜덤화 범위를 좁힌다**. 측정 순서는 9주차 민감도 순위(`sim/w09/results/randomize.md`)를 따른다
- 대상: 어깨 TQ(a2_doc) · 팔꿈치 RI85, 임시 평행 2지 그리퍼(A팀 사양 미수령), 시연 테이블 · 물체 2종
- 결과 반영: `actuator_params.json`(armature · frictionloss · damping · kp 배율) → 박종진 `build_v1.py` 재빌드, 가정값 표 S3 · S4 · S15 ~ S17 갱신, `randomize.py` 범위 = 측정 평균 ± 2σ 로 교체 후 민감도 재실행
- 공통 규칙: 한 항목 **3회 이상 반복**해 평균 · 표준편차 기록, 온도 · 날짜 · 펌웨어 버전 · 측정자 기록, 원자료(csv)는 저장소 `sysid/raw/`(대용량은 제외), 처리 스크립트는 `sysid/fit_*.py`

| 순위 | 항목 | 왜 먼저 (시뮬 근거) | 목표 불확도 |

| **3** | 물체 위치 측정 오차 (인식) | 편향 20 mm 까지 38/40, **25 mm 에서 31/40** = 벌림 여유 25 mm, 10 mm 에서 목표 오차 +2.12 mm | 편향 ≤ 5 mm |

## 2. 측정 항목 · 절차

| # | 항목 → 모델 파라미터 | 장비 | 절차 | 계산 · 판정 |
|---|---|---|---|---|
| E1 | 테이블 높이 · 기울기 → `TABLE.top`, `table_dz` 범위 | 레이저 거리계 또는 줄자(1 mm), 수준기 | ① 바닥 → 윗면 높이를 네 모서리 + 중앙 5점 측정 ② 로봇 기준(베이스 상판)에서 같은 5점을 끝점 「터치」로 재확인: 끝점을 5 mm/s 로 내리고 팔꿈치 · 어깨 전류가 정지 대비 +20 % 뛰는 순간의 FK 높이 | 평면 맞춤 → 높이 평균 · 기울기. 시연 위치마다 **오차 ≤ 2 mm** 이면 시뮬 공칭 유지, 넘으면 TABLE.top 교체 또는 터치로 매번 보정(정책 입력에 테이블 높이 추가) |
| E2 | 패드 ↔ 물체 마찰 μs · μk → `mu_pad_obj` | 패드 재질 판, 각도기(경사면), 디지털 푸시풀 게이지(0.1 N) | ① **경사면**: 패드 판 위에 물체를 놓고 천천히 기울여 미끄러지는 각 θ → μs = tan θ (10회) ② **파지 당김**: 그리퍼로 물체를 잡고(명령 파지력 F) 게이지로 아래로 당겨 미끄러지는 힘 P → μ = P / (2F) (F 3단계 × 3회) | 두 방법 차 ≤ 0.1 이면 평균 채택. 물체 2종(상자 · 원기둥) × 표면 상태(깨끗 / 먼지). **μ ≥ 0.37** 이면 3 kg · 40 N 들기 가능(여유 = μ/0.37) |
| E3 | 물체 위치 측정 편향 · 잡음 → `obj_bias`, 관측 잡음 | 카메라(미정) · ArUco 판 또는 체커보드, 줄자 | ① 테이블 위 알려진 20점(격자 50 mm)에 물체를 놓고 인식 위치 기록 ② 같은 점을 끝점 터치로도 측정(E1 방식) | 편향 = 평균 오차 벡터, 잡음 = 표준편차. **편향 ≤ 5 mm** 이면 현재 정책으로 충분(시뮬 10 mm 까지 39/40), 10 ~ 20 mm 면 정렬 단계에 손가락 접촉 탐색 추가 |
| E4 | 그리퍼 파지력 → `GRIPPER.grip_force`, `grip_force` 범위 | 얇은 로드셀(0 ~ 100 N), 전원 · 전류계 | 손가락 사이에 로드셀을 끼우고 명령 전류(또는 위치 오차) 5단계 × 3회 → 정지 파지력 | 명령 ↔ 힘 직선 맞춤, 손가락당 힘 상한. A팀 사양과 대조 |
| E5 | 관절 쿨롱 · 점성 마찰 → `frictionloss`, `damping` | 구동기 단품(링크 없이) + 링크 장착 상태, 드라이버 전류 로그(1 kHz) | 속도 제어로 ±0.05 ~ 2 rad/s 10단계 일정 속도 → 각 단계 정상 구간 평균 전류 | τ = K_t · i, τ = τ_c sgn(ω) + b ω 최소제곱 → τ_c(frictionloss), b(damping). 시뮬 가정 0 · 0.5 와 비교 |
| E6 | 반사 관성 (armature) → `armature` | E5 와 같음 | 링크 없이 전류(토크) 계단 · 처프(0.5 ~ 20 Hz) 입력, 엔코더 각도 기록 | τ − τ_c sgn(ω) − b ω = J θ̈ 회귀 → J_total. A2 로터값(어깨 0.219 · 팔꿈치 0.098 kg·m², 기어열 미포함)과 차 = 기어열 관성 |
| E7 | 백래시 → (모델 없음 → 랜덤화 항목 추가 여부 판단) | 출력축 고정 지그(바이스), 출력측 외부 엔코더 또는 다이얼 게이지(레버 0.2 m) | 출력축 고정 후 ± 작은 토크(정격 5 %) 왕복 → 모터측 엔코더의 데드존 각. 또는 출력측 · 모터측 엔코더 차를 왕복 운동 중 기록 | 데드존 각 [arcmin]. 끝점 환산 = 각 × 팔 길이(≈ 0.64 m: 1 arcmin ≈ 0.19 mm) → 1 mm 넘으면 MuJoCo 에 위치 잡음 / 데드존 모델 추가 |
| E8 | 토크 상수 K_t → `kp_x`(kp · kv 배율), 토크 예산 | 레버(0.3 m) + 추 0.5 ~ 5 kg 또는 토크 센서 | 정지 자세에서 레버 끝에 추를 달아 정적 토크 τ = m g L 를 만들고 유지 전류 기록(6단계 × 3회, 양방향 → 마찰 상쇄) | τ ↔ i 직선 기울기 = K_t. 사양 대비 차 → kp 배율. **「실제 정격 ≥ 요구 정격(필요 × 1.2)」 판정을 측정 K_t 로 다시**(팀장 11/19 기준, `sim/w10/results/torque_judge_w10.md`) |
| E9 | 제어 지연 → `latency`, Isaac `DelayedPDActuatorCfg` | 드라이버 명령 · 엔코더 타임스탬프 | 위치 명령 계단 · 처프 → 명령 시각과 엔코더 움직임 시작 시각 차, 처프는 상호상관 지연 | 지연 [ms]. 시뮬은 40 ms 까지 40/40 → 20 ms 넘으면 범위만 갱신 |
| E10 | 베이스 속도 응답 → `base_kv_x`, `TAU_B` | 베이스 바퀴 엔코더 · 외부 측정(바닥 표시 + 영상) | 속도 계단 0.2 · 0.5 · 1.0 m/s, yaw 0.5 rad/s → 1차 시간상수 | 5주차 시뮬 τ 0.380 · yaw 0.082 s 와 비교 → 전문가 정책 TAU_B 갱신 |

## 3. 일정 · 필요 지원

- 실물 수령 주차(미정)의 월 · 화: E1 · E2 · E3(환경 · 접촉 · 인식, 구동기 없이도 가능) → 수: E4 · E8 · E5 → 목: E6 · E7 · E9 · E10. **E1 · E2 는 구동기 없이 지금 할 수 있음**(테이블 · 패드 재질 · 물체만 있으면)
- 필요한 것 (팀장 · A팀 확인): 시연 테이블 위치 · 실물, 패드 재질 시편, 그리퍼 사양(파지력 · 스트로크), 로드셀 · 푸시풀 게이지 · 레버 지그 대여, 드라이버 전류 로그 방법(A2)
- 안전: 구동기 시험은 출력축 고정 · 토크 상한(정격 50 %)부터, 2인 이상, 비상정지 확인

## 4. 결과 반영 흐름

```
측정 csv → sysid/fit_*.py (평균 · σ) → actuator_params.json · 가정값 표(S3 · S4 · S15 ~ S17) 갱신
        → randomize.py PARAMS 범위 = 평균 ± 2σ → 민감도 재실행(oat · joint) → Isaac EventCfg 범위 동일하게 갱신
```
